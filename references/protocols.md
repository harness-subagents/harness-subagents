# MCP and A2A — tier A
- MCP (modelcontextprotocol.io): "a standardized way to connect AI applications to external systems" — data, tools, workflows. Application-to-tool, **not** model-to-model.
- A2A (a2a-protocol.org): open standard for communication between AI agents; agents are opaque to each other. MCP equips agents with tools; A2A links agents.
